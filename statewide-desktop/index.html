California Appraisals Beyond San Diego County

Desktop reports only beyond the in-person communities; no Drive-By or Standard reports.

Families rarely own property in just one place. An estate might include the parents' home in El Cajon, a cabin in the Sierra foothills and a rental in the Central Valley, and the trust or the court needs values for all of them as of the same date. Outside San Diego County, Brian works statewide using desktop reports built from public records, permit data, prior listing photos and comparable sales drawn from the local market around each property. His California certification is valid in every county, so the same appraiser can handle the whole portfolio. That keeps methods, effective dates and report formats consistent, which simplifies an accounting, a tax filing or a negotiated division among heirs, and it saves the family from hiring a separate firm in each county.

Desktop reports only

Past the 68 places Brian visits, orders are filled with the three no-visit formats and nothing else.

One appraiser, one standard

When several properties in different counties need values for the same estate or trust, using one appraiser removes the problem of conflicting methods and assumptions. Each report follows the same structure, so attorneys and accountants can compare them side by side without reconciling different styles.

Local sales, not averages

Every desktop report relies on actual closed sales near the subject property, selected for similar size, age, lot and location. Brian studies each market individually instead of applying county-wide trends, which matters in places where a few miles separate very different price levels.

Retrospective dates statewide

Date-of-death and date-of-separation values work the same way outside San Diego. Brian locates sales from the relevant period and uses archived listing data and records to describe the home as it existed then, which is often the only practical approach for a distant property.

When a visit is needed

Some properties simply cannot be valued well from records alone, such as heavily damaged homes or large rural parcels with several buildings. In those cases Brian will say so in the quote and can suggest how to proceed, so the client is not paying for a report that will not serve its purpose.
